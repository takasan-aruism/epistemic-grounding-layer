## 0. ★この文書が目指すもの（★増やさない。減らす）
> **★これは監査基盤ではない。** **規則を増やす文書でもない。**
> **★目的は「やっても意味の無い検査をやめること」である。** **Taka: 厳格さはリターンを示せ。**

## 1. ★中心の主張（1行）
> **検算とは「同じ答えが出るか」ではない。** **★「誤り方が違う経路を通ったか」である。**

**∴ 同じ経路を2人で流しても、それは検算ではない。** **★2人分の手間で、1人分の確からしさしか得られない。**

## 2. ★根拠（本日の実測。作り話ではない）
**本日、CC-α の計器の問題が7回出た。** **★7回とも本人が見つけた。** **★他者の再実行が見つけたものは0件である。**

| # | 何が効いたか | 実例 |
|---|---|---|
| 1 | **自分の前提（判定表）へ戻った** | 「なし」が1件残る → 直し漏れに見えた → **対象外の #6 と確認** |
| 2 | **期待と違う件数を疑った** | 引用符つきで数えて4件 → **「少なすぎる」→ 10件** |
| 3 | **計器の値域を疑った** | 配信画面に「無し」→ **その分岐は出ない ∴ 0 に意味が無い** |
| 4 | **計器が自分を数えていないか疑った** | フックが自分の commit 文を数えた |
| 5 | **0 でない値でもまず自分を疑った** | Gap の 0 詰め違いで5件を誤検出 |

> **∴ 検算を成立させたのは「2人いたこと」ではない。** **★「別の当て方をしたこと」である。**

## 3. ★区分（3つ。これ以上増やさない）
| 区分 | 定義 | **再実行の値** |
|---|---|---|
| **決定論** | **同じ入力に同じ答えしか返さない**（`grep -c`・`sha256`・テストの pass 数・差分の行数） | **★無い。再実行しない** |
| **判断** | **どこを測るか／何を対象外にするか／その答えは意味を持つ場所か** | **★在る。★ここだけ独立に当てる** |
| **人しか出せない** | **画面を実際に開く・意図が伝わっているか** | **★我々には出せない。Taka に出す** |

**★CC-α の `【伝聞・決定論】`／`【伝聞・判断】` はこの区分と一致している。** **★そのまま使う。**

## 4. ★運用（★これだけ。手順を足さない）
1. **受入の各行に、上の3区分のどれかを書く。**
2. **決定論は再実行しない。** **★「再実行していない」を欠点として書かない。**
3. **判断は、★測った本人と違う当て方で1回だけ当てる。** **同じコマンドを流さない。**
4. **人しか出せないものは、★埋めようとせず Taka へ出す。** **★受入を満たしたことにしない。**

## 5. ★この定義で「独立検算した」と書けない例（★先に書く）
- **同じコマンドを2人で流して一致した** → **★書けない**
- **配信画面で 0 件だった**（その分岐が出ない場所） → **★書けない**
- **テストが通った** → **★書けない**（決定論であり、判断を当てていない）
- **実装が「満たした」と書いた** → **★書けない**（それは伝聞である）

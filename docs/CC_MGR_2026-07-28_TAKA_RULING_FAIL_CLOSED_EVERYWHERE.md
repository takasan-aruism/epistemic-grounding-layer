## 3. 依頼（★小さく1つ）
**合流点④を fail-closed にすること。** **形は他の4つと同じ**（`_fail` 相当で「記録できなかった」を結果として返す）。
| # | 条件 |
|---|---|
| **1** | **★他の4つと同じ形にする。** **④専用の新しい形を作らない** |
| **2** | **★`G-38`（「④は fail-open。取りこぼしが起きうる」）を `CLOSED` にする。** **穴が塞がるため** |
| **3** | **★`dropped_before` / `stderr` の仕組みは残してよいが、必須条件から外す。** **fail-closed なら取りこぼしは起きない** |
| **4** | **★「成果物が失われうる」ことを、実装源とコードのコメントに1行残す。** **後から読む者が、代償を知らずに「なぜここで止まるのか」と外さないように** |
| **5** | **★止まったときに何が失われるかを、止まった時点で分かる形にする**（可能なら sandbox のパスを返り値か記録に残す）。**★できないなら「できない」と書く。無理に作らない** |

1. `ETRACE_RUN_ID` を webui から読めるように（`G-46`）

**★3以降とは混ぜない。**

## 3. 裁定 F3（`ART-` の計算を import するか、同式を書くか）→ **同式を書く。import しない**
**理由:**
1. **`egl` から `twoder` を import すると、暫定台帳より長生きする依存が1本増える。** **暫定のために恒久の線を引かない。**
2. **v1.8「層を飛ばさない・既に作ったものを使う」は、依存を増やす許可ではない。**
3. **重複は1行の sha1 であり、台帳と同時に消える。** **依存は消えない。** **消える重複 < 残る依存。**

**条件:**
- **台帳の `_meta` に、式の出所を書く**（`twoder/artifact_registry.py` の該当関数名）。**重複であることを隠さない。**
- **退役時に、この重複も一緒に消すことを退役条件に含める。**

## 3. ★画面（★v1.1 で直した所）
### 3-1. ★括弧に中身を固定しない（★MGR §2）
```
★v1.0 に私が書いた（★誤り）:
   「※ この一覧の対象外の依頼が 2件 あります（★止まっているもの）。」
   → ★完了が1件 出た日、対象外は3件になるのに、★括弧は「止まっているもの」と言い続ける。
```

> **★件数は動くのに、括弧が動かない。** **★今日 何度も直した形を、★私が最後にもう1つ作っていた。**

**★正しい形: ★出ているものだけを、数えた結果のまま名指しする。**
```
今日（完了0件）:
  ※ この一覧の対象外の依頼が 2件 あります（止まった 2件）。開いて読めます:
     ・TASK-2DER-7089D8FC   「<依頼文の先頭30字>」
     ・TASK-2DER-D6346F79   「<依頼文の先頭30字>」
     先頭30字です（全文ではありません）。先頭が同じでも別の依頼です。
  終わった依頼と止まった依頼は、進行中の集計に入りません。

完了が1件 出た日（★自動でこうなること）:
  ※ この一覧の対象外の依頼が 3件 あります（止まった 2件／終わった 1件）。開いて読めます:
```

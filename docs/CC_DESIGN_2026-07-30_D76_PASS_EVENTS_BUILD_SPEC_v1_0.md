## 1. ★直す所（★口を1つ足すだけ）
```
現在（実読）:
  workcell.py:56   def _read_events(task_id=None)
  workcell.py:114  def derive_state(task_id)
  dispatch.py:47   def next_legal_operation(task_id)
★3つとも task_id しか受け取らない ∴ 読み込み済みを渡せない。
```
| # | 直すもの | 形 |
|---|---|---|
| **1** | `workcell.derive_state` | **★省略可能な引数を1つ足す**（読み込み済み events を受け取る） |
| **2** | `dispatch.next_legal_operation` | 同上（**★受け取ったものを `derive_state` へそのまま渡す**） |
| **3** | `submit._active_2der_tasks` | **★既に1回読んでいる**（`_read_events(None)`）。**★それを渡す** |

### 1-1. ★守ること
1. **★省略したときの振る舞いを1ミリも変えない**（省略時は今までどおり自分で読む）。
2. **★既存の呼び手を1つも書き換えない**（省略できるので、触る必要が無い）。
3. **★キャッシュを作らない**（★保持しない。**1回の処理の中で渡すだけ**）。
4. **★並列化しない。**
5. **★`_read_events` の絞り込み規則を変えない**（`task_id is None or e.get("task_id") == task_id`）。
   - **★渡された events を task_id で絞る規則は、★`_read_events` と同じでなければならない**（`_ordinal` の付き方を含む）。

### 2-1. ★受入1 の示し方（★具体に決める）
```
① 変更前に、155件について (task_id, state, actor_id, claude_barrier) を1行ずつ出し、★ファイルに保存する
② 変更後に、同じものを出す（★引数を渡す版）
③ ★差分を取る → 0行であること
④ ★さらに、引数を渡さない版でも②を取り、①と差分0であること（＝受入3）
★①は変更前に取らないと二度と取れない。★先に取ること。
```
> **★これは「速くなったか」を測るものではない。** **★「答えが変わっていないか」を測るものである。**

## 2. ★★計測原則の確定（本日の全事故を説明する1本の線）
IMPL の対照設計 —— **選別（LLM）を1回だけ走らせ、その同一出力から arm A / arm B を導出する** —— が決定的だった。

> **水準（arm A の絶対値）は run ごとに 0.10 揺れる。**
> **しかし対の差（同じ選別出力から導いた A と B の差）は揺れない。** 差はフィルタが候補を変えた箇所からのみ生じ、LLM のサンプリングは両アームで共通だから。

**∴ 原則:**
| 設計 | 信頼できるもの | 例 |
|---|---|---|
| **対（同一 run 内・同一 LLM 出力から派生）** | **小さな差も信頼できる** | P3 の 誤答 −6（本件）／再観測が正解候補を10件破壊（DE-0546）／選択役が63件中1件（DE-0547）／position bias の fwd/rev 対比較 |
| **非対（別 run の集計値どうし）** | **ノイズ幅（≈0.10）を超える差のみ** | 0.5397 → 0.7143（+0.175）は可／cheap-fix +0.033 は不可 |

**これが「本日の構造的発見はすべて生き、小さな数値差の主張はすべて死んだ」ことの理由である。**
生き残った結論は**例外なく対照設計か構造観察**であり、死んだ結論は**例外なく非対の集計値比較**だった。偶然ではない。

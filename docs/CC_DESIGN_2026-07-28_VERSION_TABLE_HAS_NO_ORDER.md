## 1. 私の誤り（先に）

> **★「実物を読んだ値」と書きながら、読み方を間違えた。** **読むことと、正しく読むことは別である。**

## 2. ★MGR の「表は降順」も、いまは成り立たない【監査:CC-α・実測】
```

```
**∴ 表の並びは `v1.0` → `v2.0` → `v1.9` → … → `v1.1` である。**
- **`head -1` は `v1.0`（初版）を返す。**
- **`tail -1` は `v1.1`（最古の1つ）を返す。**
- **★最新（`v2.0`）は、先頭でも末尾でもなく2行目に在る。**

**∴ MGR の「`tail -1` は最も古い行を返す」は正しい。** **しかし「表は新しい順」は、`v1.0` が先頭に在る時点で崩れており、`v2.0` の挿入位置でさらに崩れた。**
**★どちらの規則で読んでも、最新版に届かない表になっている。**

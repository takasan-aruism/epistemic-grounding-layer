# 宛: 設計 / 監査 ―― EVO-0063 通常系が『何をしたか』を出しているかを数える（第1回測定）

## 0. 台帳から引いた正本の受入（記憶・会話から作っていない）

`GET /api/resolve?id=ITEM-2DER-EVO-0063` の `record.description` 逐語:

```
★最初の受入
 ① emit の呼び手を 機械で数える(★登録時の 設計の実測=13ファイル・18箇所)
 ② 工程ごとに『届いている／届いていない／不明』の3値

★authority = IRREVERSIBLE ／ acceptance 欄は空(受入は description に埋まっている)
```

**開始条件は満たされている** ―― `ITEM-2DER-EVO-0062` は **DONE**。
また `ITEM-2DER-EVO-0019`(Independent audit layer) は **DEFERRED**、理由の逐語が
「EVO-0063(母数を数える)の後に」。**順番も台帳の意図どおり。**

## 1. 測り方（指示の順序どおり／★コード走査 0）

`台帳` → `経路表(route_table)` → `etrace` の順。**grep もコード全走査もしていない。**
突き合わせは**別々の既存記録どうし**（`/api/etrace?task_id=` と `/api/etrace?run_id=`）で行った。
対象 = `TASK-2DER-5980A06B`（通常系 DW と Domain 側の両方が動いた実物）。

## 2. 結果 ―― 母数は経路表の 18区間

**②が9件ある**ことが本件の芯。**通常系は証拠を出している。出しているが `task_id` で引けない。**

### ★私が一度 誤った答えを出した（記録として残す）

最初、`task_trace` だけで数えて **「届いていない 12 ／ 不明 0」** と出した。
`run_trace` に当たると S01〜S06 等は**記録が在った**。
つまり私は**「起きなかった」と「観測できていない」を混ぜた** ―― 台帳の逐語が警告する
「監査層そのものが**何も見えていないのに異常なし**と判定する危険」の、向きが逆の同型。
**1つの記録だけで断定した**のが原因。

## 4. 欠陥 ―― どの既存計器が答えられないか

| # | 欠陥 | 答えられない計器 | 最小で足す物 |
|---|---|---|---|
| **A** | emit の多くが `task_id` を持たない → 9/18 区間が task から引けない | `GET /api/etrace?task_id=` | 入口側の emit へ **task_id を伝播**（Domain 側は今夜 `set_current_task` で実施済み。同じ形を入口へ） |
| **B** | **本線実行と実験実行を分ける欄が無い** | etrace の13欄すべて | 記録に **「呼び元の面」1欄**（front_door / manager / script） |
| **C** | 経路表が「必ず通る区間／条件付き区間」を持たない → ③の3件のうち S07（入口・起きたはず）と S14/S15（この走行では起きていない可能性）を**分けられない** | `route_table` | 各区間に **「必須／条件付き」1欄** |
| **D** | 経路表に Domain Manager の線が **0区間**（`domain` `material` `role` `work_unit` の語が0） | `route_table` | Domain 区間の**宣言** |
| **E** | `handoff`（送り側）が揃う区間が限られ、`receipt` 片側だけの区間が在る | `route_table` × etrace | 既存の両側規律を残りの区間へ |

**★B の補足**: `run_id` は代理にならない。今夜 `to_domain` 経由（＝本線）で動いた記録も
**19件が `run_id=None`**。有無で本線を判定すると誤る。

## 5. 実装は増やしていない

指示どおり、**答えられない分を欠陥として出すところで止めた。**
新台帳 0 ／ 新 Manager 0 ／ 自己監査器 0 ／ LLM 0回 ／ コード走査 0（受入④を満たす）。

**受入① の扱い**: 「emit の呼び手を機械で数える」は**コード走査**にあたり、今回の指示
「grep やコード全走査から母数を自作しない」と正面から食い違う。
**順序で解いた** ―― 経路表と etrace で答えられる分を先に出し、
**答えられなかった A〜E だけ**を欠陥として提示した。①の実行はその後の最小手段として保留。

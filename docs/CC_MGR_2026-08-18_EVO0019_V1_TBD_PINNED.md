## 3. v1 の範囲（Taka 逐語の連鎖）

```
PASSED も含めて 少数を 標本化する
  → 0016 の判定を 隠したまま 独立監査する
  → 見逃しが あったかだけ 記録する
  → 0017 へ 流す

```

**ここまで。** 閾値で自動介入する／別モデルを増やす／常時監査にする ―― **全部 後。**

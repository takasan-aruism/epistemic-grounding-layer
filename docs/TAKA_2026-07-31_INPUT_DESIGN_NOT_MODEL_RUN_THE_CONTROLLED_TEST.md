>

> 2. **観測値と取得手段が混在している。** ps や nvidia-smi が「既に実行済みの方法」なのか、「これから実装する候補」なのか、モデルから見て曖昧です。
> 3. **観測から何を判断させたいかが弱い。** 「現在分かっていること」「不足していること」「新規実装が必要か」を区別する出力契約になっていません。

> **Qwenに値を渡しても使えなかった、ではない。**

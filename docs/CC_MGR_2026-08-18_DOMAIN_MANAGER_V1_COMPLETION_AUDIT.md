## 4. v1 を閉じてよいか：**NO**

理由は2つ。どちらか一方でも成立すれば NO。

1. **(3)(4) が未着手。** 起動と統合が無い主体は Manager として成立しない。
2. **(2)(6) が本線外。** 部品は在るが誰も呼ばない。**Claude を抜くと止まる。**

### 反対の読みも書いておく（私はこれを採らない）

(3)(4) を「DW 状態機械が担うので Domain Manager 外」と読めば、母数は4となり全て最小経路成立＝YES になる。
**採らない理由**: DW が起動するのは実装 Actor であり、§14 の**専門 Worker（材料調査）ではない**。
ただし **この一点は私の解釈**であり、監査が覆すなら判定は変わる。
なお**この読みを採っても (2)(6) の本線外は残る**ため、v1 は閉じられない。

## 6. 閉じるために絶対必要な残り（1件だけ）

> **本線経路（front door）で、1件の案件について (2)→(6) が人手なしに走ること。**

これ1本で、未着手の(3)(4)（＝誰かが部品を起動し結果を受け取る）と、
(2)(6) の本線外が同時に解消する。**新しい部品を作るのではなく、既に在る8件を繋ぐ。**

- 新しい Manager / 新台帳 / 巨大 router は作らない
- 並列実行に進まない（Worker は**1つ**）
- RRI 外部調査に進まない
- 4件の機構欠陥は**次の本線にしない**（別工程として棚上げ）

## 4. ★これで測れたこと／測れていないこと（SPEC §3 の固定・言い換えません）
- **測れた**: **「利用可能な事実を渡すと、結果が変わるか」→ 変わる。**
- **測れていない**: **「モデルの判断力が上がったか」。**
  - 事実文「**指す対象は記録から特定できない**」は、戦略定義「**対象が何を指すか意図が不明**」と**ほぼ 1:1 で対応**します。
  - **∴ C が効いたのは「明示されたヒントに従えた」ことの証拠であって、「自力で判断できた」ことの証拠ではありません。**
  - **「賢くなった」とは書きません。「事実を渡すと当たるようになった」とだけ書きます。**

# LLMK-0009 決められなかった集合は 難しい集合では ない（★UNRESOLVED 123件の型分け）

- call_sites: （無し＝呼出点に紐づかない知識。★新鮮なのでは なく 鮮度を 確かめようが ない）

- 出所: ITEM-2DER-EVO-0121 ／ MGR 裁定「Qwen をもう一度測らない。UNRESOLVED 123件が なぜ決められないのかを型に分ける」

## 1. 何を測ったか

基準 v1（表層語だけ・commit 283d685 で固定）で標本 200 件を採点し、
どれにも当たらなかった **UNRESOLVED 123 件（62%）** を、決定論の規則で型に分けた。

| 型 | 件数 | 割合 |
|---|---|---|
| T3 述語で終わっていない（名詞止め・体言止め） | 77 | 63% |
| T6 述語は在るが 基準の語彙に1つも当たらない | 44 | 36% |
| T5 見出し・箇条書きの断片 | 2 | 2% |

★材料は「文」ではなく **台帳の記帳の断片**である。基準の語彙は
「した／する」のような **述語で終わる文** を前提にしていた ∴ 6割は **材料と設問の形が合っていない**。

## 2. ★一番効いた実測

UNRESOLVED 123 件で **人(gold)と Qwen の一致 = 83/123 = 67%**。
一方、基準が **決められた 77 件** での一致は **46/77 = 60%**。

> ★**決められなかった集合の方が、決められた集合より 一致率が高い。**
> ∴ **UNRESOLVED は「難しくて決まらなかった」のではない。基準の語彙が届いていないだけ。**

★これは「測ったら悪かった」ではなく「**測る前から 基準の側が 当たっていない**」に属する。

## 3. ★v2 を作ろうとして 失敗した（★出荷しない）

手続きを **語を見る前に** 固定した：①人とQwenが一致した83件だけを材料にする
②id順で交互に2分割（作る側42／試す側41・★私が選ばない）③作る側だけから2〜6字の
部分文字列を数え、1つのラベルにしか出ない語を採る ④2件以上 ⑤試す側は一度も見ない。

結果、試す側で UNRESOLVED は 41→19 に減り、新たに決めた 22 件の正解は **19/22 = 86%**。
**ここで止めれば「効いた」と書けた。**

★**対照を取ったら 負けた**：同じ22件を「**全部 PROBLEMS と答えるだけの器**」に掛けると **20/22 = 91%**。

> ★**v2 は 多数派に勝てていない。語彙を見つけたのではなく、クラスの偏りを拾っただけ。**
> 機械が採った語も `てい` `いる` `い。` `んだ` のような **意味の無い断片**だった（★意味のある語は `無い`/`が無い` のみ）。

## 4. 次に使える形

- ★**一致した集合から語彙を機械的に採ると、多数派バイアスを拾う。**
  採った語彙は必ず「**全部 多数派と答える器**」と **同じ分母で** 比べる。
- ★**UNRESOLVED の多さを 難しさの証拠に しない。** まず 材料の形（述語で終わるか）を見る。
- ★この標本では **PROBLEMS が 68%** を占める ∴ どんな器も 68% は 無条件で当たる。
  **68% を下回らない限り「効いた」と書けない。**

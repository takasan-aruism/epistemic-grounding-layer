## 結果（同一 metric=seed平均・arm-C2 0.83 汚染値とは並べない）
| アーム | 方式 | 戦略一致(seed平均) |

## ★ 何が起きたか（正直に・ESDE 先行実績どおり）
1. **YES 膨張は実在した**（ESDE の予告どおり）: 選別役の YES 数は平均1.67・**18/63(29%)が≥3個**。ESDE の対策 prompt（既定NO/員数明示/理由必須/弱いYES禁止）で平均は 1-2 に収まったが、29% は依然膨張。
2. **論理矛盾する YES**: DIRECT+INTENT_PROBE(4)・DIRECT+PREMISE_PROBE(4)・DEFER+BMV(5)。独立判定ゆえ、同じ依頼に「直接答える」と「確認が要る」を同時に YES ＝候補集合が論理的に不整合。
3. **NO_CANDIDATE=12**（7戦略すべてに NO＝答えが出ない）。捏造で埋めていない（正直な空）。
4. **再観測は accuracy を下げた**: 監査 flag 20件を再観測→YES を平均1.67→1.05 に強く削減したが、**正しい YES も一緒に落とし**（再観測 reduced 20/20）、NO_CANDIDATE を増やして accuracy を悪化させた（0.556[再観測なし初回]→0.46[再観測あり]）。＝「制約付き再観測」は過剰締めのリスク。

## ★ 構造的に効いたもの（役割分割の genuine な収穫）
- **選択役の順序バイアスが激減**: 候補順 fwd/rev の一致 **0.96**（arm-C3 の二択 position bias 0.65＝35%変動 に対し大幅改善）。**候補集合から選ばせる形は順序に強い。**
- **SELECTOR_OUT_OF_SET=0**: 選択役が候補集合の外に出ない構造的制約が完全に機能。
- **監査役が矛盾/膨張を決定論で全件可視化**（LLM 不使用）。

## 総合評価（過大主張しない）
- **役割分割単体では意図調べは解けなかった（≈0.5・木と同水準）**。真のボトルネックは集計構造でなく、**model が各戦略に寛容に YES を付ける（膨張+矛盾）**こと。これは「LLM を強くするな・集計を強くせよ」の限界＝**選別役の判定そのものが甘い**と、集計を工夫しても candidate set が汚れる。
- 前回2連続で統制前に見出しを立てた反省を踏まえ、今回は **効かなかった結果をそのまま**出す。役割分割の価値は精度でなく「順序頑健・構造制約・矛盾の可視化」に限られた。
- **次の設計提案（IMPL 入力・DESIGN 判断）**: (a) 選別役の膨張は prompt でなく **1呼出で7戦略を相対比較させ「最大1-2にYES」を強制**する形（独立判定をやめ相対化）＝ESDE の「員数」を1呼出内で効かせる。(b) 矛盾ペア(DIRECT+probe)は監査で**候補から機械除外**して選択役へ。(c) 再観測は「削れ」でなく「矛盾ペアだけ解消せよ」に限定（過剰締め回避）。

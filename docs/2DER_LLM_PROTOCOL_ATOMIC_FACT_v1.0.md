## 0. 何をするものか（1行）

**1本の文章を、後続処理が再利用できる `subject / predicate / object_or_value` の
カードへ、一件ずつ独立に変換する。**

## 1. なぜ要るのか（★Taka 逐語 2026-09-01）

> 原文さえひろっておけば、内部検索で引っかかる。それが明細化されたものか原文か、で言えば
> 実は**原文の方が信頼度も高い**。しかし、**構造化されたものをAIは好む**。つまりそういうものだ。

∴ ★**原文が正本。カードは AI 用の構造。二重管理である。**
★カードが原文を置き換えることはない。★取りこぼしは事故ではない。

## 2. 入力

- **材料**: 1本の文章（★`CONTENT`）。
- ★**索引（検索結果一覧・目次・リンク集）は 入力に しない**（→ §6 の実測）。

## 3. 出力（★これだけ）

```json
{
  "facts": [
    {"id":"F001","subject":"...","predicate":"...","object_or_value":"...",
     "context":null,"source_basis":"..."}
  ],
  "residual": [ {"source_basis":"...","reason":"residual に残した理由"} ]
}
```

## 4. 約束（★守るべきこと・逐語）

1. source_basis は SOURCE 内の記述を**そのまま引用**する
2. 各記述の**担い手**を subject にする（文法上の主語や全体の主題ではない）
3. predicate は**一つの意味**だけを持つ短い語句
4. object_or_value は**値そのものだけ**（説明文を入れない）
5. context は**成立範囲だけ**（不要なら null）
6. 一つの FACT に**一つの述語**だけ（複数なら分割する）
7. FACT へ変換しなかった記述は **residual に残す**
8. 出力は **facts と residual の2つだけ**

## 5. 呼び方（★実測で決めた値）

|---|---|---|
| モデル | Qwen3.6-35B-A3B | 実走 |

## 6. ★成立する範囲（★測って分かった境界）

**分母＝10テーマ（Wikipedia 本文 16,464字に揃えた）／FACT 3,341件。**

### 6-1. 本文に当てたとき（★成立する）

| 約束 | 実態 |
|---|---|
| id 形式 | **100%** |
| context が成立範囲だけ | **違反 0%** |
| facts と residual だけ | **余分な鍵 0** |
| 引用が原文に在る | **93%** |
| subject が原文に在る | **95%** |
| object が説明文になっている | 4% |

### 6-2. ★索引に当てたとき（★成立しない）

検索結果一覧（1KB 程度のリンク一覧）3件に当てた実測：

- **プロトコルは全部守られる**（完走 3/3・引用が原文に在る **31/31 = 100%**）
- ★**しかし出るのは「所在」のカードだけ** —
  「量子力学 入門」は **21件中16件（76%）** が `has_url` / `title` / `publisher` / `platform`。
- ★**設問の失敗ではない。材料に中身が書かれていないので出しようがない。**

∴ ★**呼ぶ前に材料が CONTENT か INDEX かを判別する。**
∴ ★**INDEX から出たカードを CONTENT のカードと同じ棚に置かない**（内部検索で
「中身が在る」と誤認するため）。

### 6-3. ★residual は取りこぼしを全部は拾わない

10テーマ中 **3件で residual が 0件なのに原文の被覆が 54% / 52% / 34%**。
落ちた 58,679字の内訳は **UI・ナビ 18,305 ／ 一覧の羅列 15,710 ／ 目次 8,142 ／
脚注 2,829 ／ ★本文らしい 13,693（23%）**。

∴ ★**77% は捨てて正しい物**（Wikipedia の UI・武将名の羅列）。
★**約束7が守られていないのは事実だが、原文が正本である以上これは事故ではない。**

## 7. 使ってよい場面 / 使ってはいけない場面

| | |
|---|---|
| ★使える | 1本の文章。網羅性の高い資料（Wikipedia 等）。★材料が CONTENT と判っている |
| ★使えない | 検索結果一覧・目次・リンク集（→ 所在カードしか出ない） |
| ★未測定 | 広告主体のページ・本文の判別が難しいページ（★Taka 指摘 2026-09-01）。★測っていない |

## 8. 測っていないこと（★0件と書かない）

- 広告ページ・低品質ページでの挙動（★Taka が指摘した範囲。**未測定**）
- 取得先の安全性（★Taka 指摘「セキュリティ上のリスク」。**Inference Control の領分外**）
- CONTENT / INDEX の判別器そのもの（★案は出したが**実装していない**）

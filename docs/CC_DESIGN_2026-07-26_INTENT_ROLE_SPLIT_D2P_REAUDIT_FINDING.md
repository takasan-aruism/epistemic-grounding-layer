## 3. では 0.54→0.71 の真因は何か（＝ここが本当の収穫）
C が A と違う点は 2 つだけ:
1. **7戦略を1呼出で全部見せる**（相互比較が起きる）
2. **員数を構造で強制（最大2 YES）** → **YES 膨張が完全消滅（≥3 が 19→0）**、YES 平均 1.79→0.97、**NO_CANDIDATE 14→3**

→ **これは ESDE の mapper そのものの形である。** `mapper_a1.py` は「1呼出・48スロット全部・既定0・員数明示・自己点検」であり、**選択（top-k）は softmax の決定論**が行う。**ESDE に「2つ目の LLM 役割」は無い。**

**＝我々は ESDE を『選別役＋選択役』と読んだが、実際の ESDE は『員数制約付きの1回の観測（LLM）＋決定論の確定（機械）』だった。忠実な移植は C であり、C が効いた。**

**これは Taka の原理そのものへの回帰である**: 「LLM は判断のみ・弁別は決定論集計」。2つ目の LLM 役割は不要どころか、動いた唯一の1件で外した。

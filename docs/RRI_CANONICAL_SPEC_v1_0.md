## 1. RRI の目的（逐語）
> **人間の曖昧な言葉を、そのまま後段へ流さず、2DERが保存・検索・判断・実行できる具体的な要求へ育てる。**

## 2. RRI が保証する状態（逐語）
> **DWへ依頼を渡す時点で、少なくとも以下が揃っている。**
> * **依頼者と発話者**
> * **元の逐語**
> * **文脈**
> * **意図**
> * **曖昧さ、不足、矛盾**
> * **必要な前提情報**
> * **調査済み情報と根拠**
> * **未確認事項**
> * **実行目的**
> * **制約**
> * **完了条件**
> * **保存先や案件との関係**

## 3. 禁止事項（逐語）
> * **生の依頼文をそのままDWへ渡さない**
> * **台帳の直接参照で不足を補わない**
> * **4軸を生成せずに、LLMの直感だけで7戦略を選ばない**
> * **判断結果の根拠を保存せずに次工程へ進めない**
> * **不足情報を暗黙に補完しない**
> * **RRIを単なるルーターとして実装しない**

## 4. 裁定
### (1) 差は分布で出す【設計:CC-α → 以後の規律】
- **この計器で差を主張するなら、単発 run でなく複数 run（最低10）の分布を出す。** 平均だけでなく**範囲**も出す。
- **単発比較は禁止**（本日の事故の5例目になる）。
- **【設計:CC-α】温度を 0 にするかは別途検討**。ただし **温度0は「測る対象」も変えてしまう**ので、変えるなら**変更前後で水準（平均）が動くかを先に測る**こと。**分散を消したいだけで水準を動かしては本末転倒。**

### (2) ★`NO_CANDIDATE` に戦略ラベルを捏造しない — フォールバック案は却下【裁定】
IMPL の発見: `CONTEXT_RESOLVE` が唯一の候補だった回が7件あり、除外すると候補が空になる。IMPL は「`INTENT_PROBE` にフォールバックする案」を**実装せず裁定を求めた**（正しい判断）。

**却下する。理由**: それは**モデルが出していない答えを我々が作る**ことであり、**我々が3度目撃して直そうとしている「空白を埋める」振る舞いを、我々自身がやる**ことになる。

**代わりに【設計:CC-α】**:
- **`NO_CANDIDATE` は「戦略が決まらなかった」という事実として保持する。**
- **その時の正しい振る舞いは「聞き返す」だが、それは *結果* であって *戦略ラベル* ではない。** 出口として `CLARIFY` に落とす（既存 `preflight_gate` の `CLARIFY_FIRST` と同じ思想）。
- **採点では `NO_CANDIDATE` を「誤答」と同列に数えない。別枠で数える。**

### (3) ★指標が見落としているもの（IMPL の観察を採用）
7件の `NO_CANDIDATE` は**期待戦略がすべて「聞き返す」型**（INTENT_PROBE 5 / PREMISE_PROBE 2）だった。
- ＝ **「自信を持った誤答」から「正直に答えない」に変わった。**
- **現在の指標はラベル一致しか見ないので、この変化を改善として見られない。**
- **【設計:CC-α】** 以後、**「誤答」と「答えない」を分けて報告する**（本日の「回答時精度」と同じ考え方）。**P3 は精度を上げなかったが、挙動は改善した可能性がある。** 断定はしない。

## 0. Taka 逐語

> そもそも Claude だろうが 揺れる。★字面の揺れと 意味の揺れが 重要で、
> ★意味として通るか を 五段階評価させる方針で テストをしなおす

## 1. 2つの揺れを分けて測った（同じ文書・同じ材料）

| | 実測 |
|---|---|
| **字面の揺れ** … 同じ文書を2周して候補の文字列が一致するか | **11/37 = 30%** |
| **意味の揺れ** … 同じ候補に付く評点が3周とも同じか | **23/24 = 96%** |
| 　　　　　　　　±1 に収まるか | **24/24 = 100%** |

★**候補の7割が入れ替わっても、意味の評価はほぼ動かない。**
∴ ★**「一致率30%だから使えない」は誤り。**★測っていた物が字面だった。

## 2. 器が甘いのではない（★対照）

本物3件に偽6件（本文に書いていないこと）を混ぜて3周：

| | 評点の中央値 |
|---|---|
| 本物 | **4** |
| **偽** | **1** |

★**偽に4以上を付けた回数 0/18。**★器は甘くない。

## 3. ★1件ずつ聞くと安定する（★LLMK-0011 の当て込み）

| 聞き方 | 本物の評点（3周） |
|---|---|
| 6件まとめて | `[1,1,4]` `[4,1,4]` — ★周ごとに 1 と 4 が入れ替わる |
| **1件ずつ** | `[5,5,5]` `[4,4,4]` `[5,4,5]` — ★ほぼ動かない |

★**出力が短いほど再現する**（LLMK-0011）が、評点にもそのまま当たった。

## 4. なぜ5段階が効くのか（★過去の知識が支えている）

- **LLMK-0005**：閉じた6語から**1つ**選ぶ設問は 3seed 安定 **90%**。
  複数選択＋自由文は byte 7〜8/8 が相違。★**安定を決めるのは課題の側＝出力の形**。
- **LLMK-0003**：語彙が上限。9語→4語に畳むと一致 57%→75%（LLM 呼び出し 0回）。
- **LLMK-0011**：長い出力は seed でも再現しない。短い出力は決定論。

★**5段階から1つ選ばせる形は、過去の実測が「最も安定する」と言っていた形**である。
★**私は Phase1 を「複数＋自由文」で作っていた**＝自分の知識が否定していた設計だった。

## 5. 使える形

- ★**候補の一致率を安定の指標にしない。**★字面を測っている。
- ★**意味が通るかは 5段階（閉じた集合）で聞く。**★1件ずつ聞く。
- ★**偽の項目を混ぜて器を検算する。**★偽に高得点が付くなら、その評点は読めない。
- ★**再現しないことを消そうとしない。**★字面は揺れる前提で、意味の側を数える。

## ★追記 2026-08-31（★Taka「5段階は雑になるかも。他に案は」）

### 過去の知識から3案を出して、同じ材料で比べた

| 案 | 出所 | 中身 |
|---|---|---|
| **A** 言い換え一致 | LLMK-0006「正解なしで数える」 | 同じ問いを3通りの言い方で聞き、答えが割れるかを数える |
| **B** 2値に畳む | LLMK-0003「語彙が上限。9語→4語で 57%→75%」 | 5段階をやめて yes/no にする |
| **C** 引用→機械照合 | LLMK-0007「材料からラベルへ漏らさない」 | LLM には引用だけ出させ、**原文照合は機械** |

### ① 明確な材料（本物4・偽4）では 3案とも差が出ない

| | 本物を通す | ★偽を通す |
|---|---|---|
| A / B | 4/4 | **0/4** |
| C | 3/4 | **0/4** |

★**偽を弾く力は 5段階も含めて全部同じ。**★ここでは選べない。

### ② ★境界の材料（書いてはいないが読み取れる 6件）で分かれた

| | 3周とも同じ判定 |
|---|---|

★**5段階と2値は同じ。C は半分しか安定しない。**

★**目盛りの数は効いていない。**

### ★∴ いま言えること（★これ以上は測っていない）

- ★**目盛りを増やしても減らしても変わらない。**★5段階の 4/5 の揺れは「雑」ではなく、
  **境界そのものが文章に無い**ことの現れ。
- ★**C（引用→機械照合）は判定器としては弱い**が、★**引用が取れたかどうか自体が情報**である。
  実測では 三権分立 0/3・国民主権 3/3 と、★**引用の取れ方が材料の性質を分けている。**
- ★**使い分け**：★**書いてあるか**は C（機械照合）で決める。★**読み取れるか**は 5段階か2値で聞く。
  ★**両方を1つの数に潰さない。**

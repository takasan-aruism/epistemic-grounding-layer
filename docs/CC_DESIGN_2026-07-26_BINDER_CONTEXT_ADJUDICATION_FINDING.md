### (a) の中身（IMPL 案より小さい）【設計:CC-α】
1. **`preceding_utterance_ref` を記録時に書く。** 発話記録時、**同一 `conversation_id` の直前発話 id** を入れる。**`phase0.utterances()` は記録経路で既に利用可能**（`submit.py:151`）＝**その場で決定論的に求まる。新しい情報源は要らない。**
2. **実 ts を渡す。** 配管は既存（§1-1）。**既定のハードコード値に落ちた記録を後から見分けられるよう、既定に落ちた事実を記録する。**
3. **前向きのみ。過去は救えない。** これを隠さず明記すること。

**性格**: これは機能追加ではなく **retention（記録の規律）の補修**である。Taka が既に判定した「**後から直させる系＝なし／過去引き＝あり**」の後者に属する。[[2der_retention_over_detection]]（**この memory 自体は【伝聞・未検証】であることを明記**）。

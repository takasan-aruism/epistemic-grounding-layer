## 0. なぜ今これなのか（問題の直接治療）
- IP1/IP2「あれ/それ」が menu 是正でも直らず、**"文脈の捏造"（DE-0545）3度目**。原因＝**「前提曖昧→probe」を7戦略の1択として競わせ**、LLM が probe を避けて文脈を捏造。
- → **曖昧検知を戦略選択の"手前"の独立ステージにする**と、6択と競合せず robust に。＝Taka の「一段別処理」。

## 1. 構造の叩き（縦串/意図調べへの差し込み）
```
[入力] → [★前提曖昧検知ステージ(新・独立)] → [意図調べ 4軸→7戦略]
             ├ 曖昧(指示語/前提未成立/揺れ) → ユーザに"潰させる"(聞き返し=probe に直結)
             └ 明確 → そのまま戦略選択へ
```
- **狙い＝"LLM に曖昧を推測させない"**。曖昧なら**最初にユーザが潰す**（＝揺れ検出システムの目的そのもの：先に潰せば回答精度が上がる）。
- 判定は**焦点を絞った検知**（"前提が成立しているか / 指示語の対象が特定できるか / 語が揺れていないか"）＝7択の総合判断でなく**専用の小判定**。判断=LLM/構造=決定論の原則は維持。
- 効果は **PREMISE_PROBE / INTENT_PROBE（聞き返し）に直結**＝後者の縦串で監査が指摘した「probe→再開は本丸・返答を検証なく飲むな」の防御とも一体。

## 1. ★答えを受ける — `de_admission` は矛盾していなかった
```
EGL の台帳は2つ。書き手はそれぞれ1つずつ:
  egl/data/events.jsonl            ← core.append_event（観測・取得の object graph）
  egl/DESIGN_EVIDENCE_LEDGER.jsonl ← de_admission（設計根拠 DE）
```
> **∴ `de_admission` の「ONLY sanctioned writer」宣言は★自分の台帳についてのものであり、正しい。**

**塞いでいたら、★別の台帳の正規の書き手を「抜け道」として扱ったまま固定していた。**

## 2. ★DEFER 定義の是正（別解にしてはいけない件）
現行定義が重複しており、model は**定義どおりに**答えていた:
- `INTENT_PROBE` = 「対象が何を指すか意図が不明で、調査前に極小の確認質問が要る」
- `DEFER` = 「不正形・**文脈不足・要明確化**で、今は保留すべき」 ← **INTENT_PROBE を丸ごと飲み込んでいる**

実測: IP1「あれ、どこにあったっけ？」IP2「それ、その後どうなった？」が **DEFER ×3 seed**（arm-D2' C 構成）。
**応答が実質変わる**（小さく1つ聞き返す ／ 今は保留する）ので別解にしない。**定義を狭める。**

- **新定義**: `DEFER` = 「**不正形・解釈不能で、意味のある聞き返しすら組み立てられない**」
  - 「文脈不足」「要明確化」の語を**削除**する（聞き返せる余地があるものは probe 系へ）。
- **予測（必ず実測で検証）**: IP1/IP2 の 6 件が回収される見込み。**回収されなければ「されなかった」と正直に報告**（私の仮説が外れたことになる）。
- **副作用の確認**: DF1「asdf ;; // @@@」DF2「。。。！？！？」が **DEFER のまま保たれているか**を必ず確認（狭めすぎて不正形が拾えなくなったら本末転倒）。

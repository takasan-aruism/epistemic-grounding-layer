## 2. 測定（新しい12 run・裁定後の指標）【監査:IMPL】

### ★2-1. 読み方（過大にしない）
- **精度の主張はしません。** +0.0068 も +0.0014 も、後述のノイズ幅より小さいです。
- **構造の主張はできます**: この差は**同一 run 内の対照（同じ選別出力から2アームを導出）**で出ているので、CC-α が §2 で「生き残る」と分類した種類の結論です。**P3 は誤答を6件減らし、うち5件は答えなくなり、1件が正解になった。正解は1件も壊していない。**
- ＝ **P3 の正味の効果は「精度向上」ではなく「構造的にあり得ない自信を取り下げさせたこと」。**

## 3. ★再現性について、さらに悪い知らせ【監査:IMPL】

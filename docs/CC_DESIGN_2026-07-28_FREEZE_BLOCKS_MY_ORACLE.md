## 3. BUILT 様式を2軸にする（MGR §2 の指示）
**「1つに丸を付けさせる欄の設計のほうが誤りだった」を受ける。** **次の SPEC から次の形にする:**

- [ ] REACHED_RUNNER（run_runner に到達した）
- [ ] SANDBOX_ARTIFACT_READY（成果物が出て、受け取れた）
- [ ] BLOCKED_BEFORE_RUNNER（契約 / token / gate などで手前で止まった）

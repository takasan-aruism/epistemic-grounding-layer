## 1. ★私の前提が誤っていた（訂正する）
**私は「`/api/resolve` が `RUN-` を解決できるようにするのが最小のはず」と書いた。** **★誤りである。**
```
twoder/ids.py の docstring: OBS-/SRC-/ARUN-/★RUN-/LEG-/SNAP- は EGL の所有
egl/egl/core.py:289        : EGL は今も RUN- を発行している
```
> **∴ `resolved:false` は「口が無い」ではなかった。** **★口は在り、EGL に転送され、EGL に無かった。**

## 2. ★裁定 — `RUN-` を EGL から取らない
**理由:**
1. **★EGL が今も発行している。** **奪えば既存の id が壊れる。**
2. **★いま 2DER は、実在する id を「穴だ」と報告している**（`ids.py` の原則「an id that does not resolve is a hole」を裏切っている）。**これは我々が本日作った defect である。** **早く消す。**
3. **★prefix を変えるのは etrace 側である。** **etrace は本日作った。EGL は前から在る。** **後から来た方が動く。**

**∴ `etrace` の `run_id` の prefix を、★所有されていないものに変えること。**
**★どれにするかは指定しない。** **`ids.py` と `estimation_basis_binding.py` の両方の一覧に無いことを実測で示してから選ぶこと。**

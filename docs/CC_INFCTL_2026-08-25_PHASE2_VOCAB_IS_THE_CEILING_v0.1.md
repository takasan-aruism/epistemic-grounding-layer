# 分類の上限を決めていたのは 語彙だった ── Phase 2 の移管実測 v0.1

2026-08-25 ／ instance=Inference Control ／ 仕様 §13 Phase 2 + §6(移管判定)

## 0. 何を測ったか

Phase 2 の単位は **呼び手**（呼出点ではない → LLMK-0002）。呼び手 **56関数 / 77実行点**。
Claude が先に 56件へラベルを付け（**Qwen を走らせる前に固定**）、同じ材料・同じ閉じたメニューで
Qwen 35B-A3B に分類させ、**一致率**を測った。採点は外側で決定論。

## 1. 実測（一致率）

| 周 | 変えたもの | 一致 |
|---|---|---|
| 1周目 | ― | **23/56 = 41%** |
| 2周目 | **設問だけ**直した（既に測ってある `answer_used` / `prompt_literal_chars` を材料に入れ、語の境界を規則で書いた） | **32/56 = 57%** |
| 3周目 | **材料を足した**（呼び手が組んだ prompt の実文・規則を「一次関数の値」と「呼び手の話」に書き分け） | **31/56 = 55%** |

**★材料を足す方向は効かなかった**（57% → 55%）。∴ 不足は材料ではない。

## 2. 上限は Qwen の能力ではなく 語彙だった

- **Qwen 自己一致（同じ設問・seed 0/1/2 が全部同じ）= 35/56 = 62%**
  ∴ **38% は temperature=0 でも揺れる**（LLMK-0001 と同じ現象）。
- **私と食い違った 25件のうち 12件は Qwen が3seed 安定**していた ＝ **どちらの読みも成り立つ**。
- 食い違いの型は1つに集中: **私=CLASSIFY / Qwen=EXTRACT が 11件**。

### ★語を畳むと上がる（追加の LLM 呼び出し 0 回で測定）

2周目の予測をそのまま使い、**ラベルの写像だけ**変えて再採点した。

| 語彙 | 一致 |
|---|---|
| 9語（元） | 32/56 = **57%** |
| **CLASSIFY と EXTRACT を1語に畳む** | 42/56 = **75%** |
| + NAME も畳む | 42/56 = 75% |
| + 自由文（INVESTIGATE/GENERATE/CONSULT）を1語に | 43/56 = 77% |
| **4語**（STRUCTURED / FREE_TEXT / MEASURE / PASSTHROUGH） | 44/56 = **79%** |

**∴ 境界が1つ重なっているだけで 18ポイント落ちていた。**
「モデルが弱い」でも「材料が足りない」でもなく、**分類語彙の欠陥**だった。

## 3. 決定論で境界を決められるか（★試して 失敗した）

仮説＝「CLASSIFY と EXTRACT の境界は、突き合わせる閉じた語の集合が module に在り、その語が prompt に並んでいるか」。
実測＝ **CLASSIFY 23件のうち 条件を満たしたのは 1件**（EXTRACT は 0/6）。**外れ**。
理由＝ prompt は**さらに1段上**（`build_prompt` など）で組まれるため、呼び手の関数本文には語が無い。
★この負の結果を残す（次に試すなら prompt 構築関数まで辿る必要がある）。

## 4. 移管判定（仕様 §6）

**移管しない。** 理由は3つとも実測:

1. 一致 79%（4語）は **1人のラベル付け**との一致であって、外部 acceptance ではない。
2. **Qwen 自己一致が 62%**（9語）＝ 同じ問いを3回引くと 38% が動く。安定の土台が無い。
3. 私の gold 自体が **INFERRED**（成熟度の梯子で MEASURED に達していない）。

∴ 現時点では Claude のラベルを正とし、**Qwen は候補生成に使える**が判定は渡さない。

## 5. 再利用できる形（条件 → 操作 → 結果）

- **条件**: LLM に分類させたら一致率が低い。
- **操作**: ★語を増やす／材料を足す 前に、**食い違いの型を数える**。
  型が1つの語の対に集中し、かつ **その食い違いが seed 越しに安定**しているなら、原因は語彙。
  **重なる2語を畳んで、追加の呼び出し 0 回で再採点する。**
- **結果**: 実測 9語 57% → 4語 79%。1つの境界を畳むだけで +18pt。材料追加は −2pt。

## 6. まだ測っていないこと

- 4語での **Qwen 自己一致**は測っていない（9語で 62% とだけ分かっている）。
- 私の gold を **別の人/別のモデル**と突き合わせていない（1人ぶんの正解しか無い）。
- 呼び手の **実行回数**（走行数）は測っていない。台帳の CALLER は静的な登記である。

## 3. ★A の実装（`/command` の JS・6箇所）
### 3-1. ★共有の1関数にする（6箇所に同じものを書かない）
```
askJSON(url, opts) の意味:
  1. fetch する
  2. ★例外（ネットワーク層で失敗）  → {kind:"NO_RESPONSE", detail:<例外の文字列>}
  3. ★r.ok が false            → {kind:"REFUSED", status:r.status}
  4. ★JSON として読めない        → {kind:"UNREADABLE", status:r.status}
```

### 3-2. ★出す文言（★今日の規律をそのまま当てる）

3. **★成功時の挙動を変えない。** **retry・再送を足さない。** **新しい endpoint・新しい状態を作らない。**
4. **★色を使わない**（`ok` も `bad` も足さない）。**★事実であって評価ではない。**

## 2. 変更点（2つだけ・thin）
### 2-1. `preflight_gate.next_legal_operation()` に事実行を追加する
**現状**（実読済）:
```
数値ゲート     → 定型文を逐語で返す
それ以外        → "…required to proceed: <slots を / で連結>…"
```
**変更後**:
```
数値ゲート     → ★1文字も変えない（逐語固定）
それ以外        → 事実行を「required to proceed:」の前に追加する
```
**文面（DESIGN 指定・IMPL は考えない）**:
| 判定（既存出力） | 追加する行 |
|---|---|
| `anchoring == "UNRESOLVED"` | `直前の文脈は記録に存在しない。` |
| `anchoring == "LOW"` | `支配的な文脈が定まらない。` |
| 指示語あり・束縛先なし | `「<語>」が指す対象は記録から特定できない。` |
| 接地 `NOT_FOUND` | `「<対象>」は記録に見つからない。` |
| 接地 `UNKNOWN` | `「<対象>」が記録にあるか判定できない。` |

**禁止**: 行動を示唆する語を足さない（「だから聞き返せ」等）／戦略名とその定義語を入れない／**入力ごとに文面を変えない**。

### 2-2. 段3e のメニューを4択に絞る
- **`DIRECT` / `CONTEXT_RESOLVE` / `CHOICE` / `BOUNDED_MULTI_VIEW` のみ**。
- **`INTENT_PROBE` / `PREMISE_PROBE` / `DEFER` を外す**（3d を通過した入力には「止まる理由が無い」ので、定義上あり得ない）。
- **3e に渡す事実は「在る」系のみ**（`anchoring in {MEDIUM,HIGH}` の `直前の文脈が記録にある: …`）。**「無い」系は 3d へ移ったので 3e に渡さない。**

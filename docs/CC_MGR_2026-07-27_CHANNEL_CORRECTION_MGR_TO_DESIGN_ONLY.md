```
MGR      : 全体の管理 / 基本設計・方針・優先順位 / 裁定 / Taka への報告 / commit・push

   ↓
```

- **MGR は実装に依頼しない。実装しない。** 実装への着手指示・実行可否・受入条件の細目は**すべて設計/監査が出す。**

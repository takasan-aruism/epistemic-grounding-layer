## 2. ★渡す事実の文面（**DESIGN が指定する。IMPL は考えない**）
**決定論の判定結果を、そのまま平叙文にする。** prompt の**依頼文の直後**に、以下の見出しで置く:

```
記録から機械的に確認した事実:
- <該当する行のみ>
```

| 判定 | 出す行（**この文面で固定**） |
|---|---|
| `context` が空 | `直前の文脈は記録に存在しない。` |
| `context` が非空 | `直前の文脈が記録にある: <context 本文>` |
| 指示語があり束縛先なし | `「<指示語>」が指す対象は記録から特定できない。` |
| 指示語があり束縛先あり | `「<指示語>」は記録上の <対象> を指しうる。` |
| 存在照合 `NOT_FOUND` | `「<対象>」は記録に見つからない。` |
| 存在照合 `UNKNOWN` | `「<対象>」が記録にあるか判定できない。` |
| 存在照合 `GROUNDED` | `「<対象>」は記録にある。` |

### ★禁止（守らないと測定が無意味になる）
- **「だから聞き返せ」「確認が必要だ」など、行動を示唆する語を足さない。** 足したら**答えを教えたこと**になる。
- **戦略名（`INTENT_PROBE` 等）とその定義語を事実文に入れない。**
- **fixture ごとに文面を変えない。** **上表の規則を全 fixture に一様に適用する。**（IP1/IP2 に有利な事実だけ足すのは cherry-pick）
- **該当しない行は出さない**（無理に埋めない）。

## 3. ★この実験が測れること／測れないこと（先に固定する・後から言い換えない）
- **測れる**: **「利用可能な事実を渡せば、結果が変わるか」。** 実運用ではこの事実は**既に手元にある**（P2/P4 が決定論で出している）ので、**渡すのは正当**である。
- **測れない**: **「モデルの判断力が上がったか」。**
  - **事実文「指す対象は記録から特定できない」は、戦略定義「対象が何を指すか意図が不明」と ほぼ 1:1 で対応する。**
  - **∴ C が効いた場合、それは「明示されたヒントに従えた」ことの証拠であって「自力で判断できた」ことの証拠ではない。**
  - **報告でこれを混同しないこと。** **「賢くなった」と書かない。「事実を渡すと当たるようになった」と書く。**

## 4. 受入（**片方だけでは採用しない**）
1. **★核心: `IP1`/`IP2` が `INTENT_PROBE` に来るか**（per-fixture で出す）。**来なければ「来なかった」と書く。**
2. **★非回帰: 既に正しかった fixture を壊していないか。** **事実を渡したせいで、A で正解だったものが誤答に変わっていないか**を per-fixture で示す。**（増やすより壊さない方が重い）**

4. **★介入後、誤りが「止まる側」と「動く側」のどちらへ移ったか**（D-5 で私が受入に入れ忘れた項目・今回は必須）。

6. **投げる前に呼出数と並列の有無を出す**（IMPL 自身の申し送り）。

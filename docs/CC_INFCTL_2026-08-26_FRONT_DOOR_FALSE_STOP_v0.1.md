# front door の誤停止を 正解なしで数える v0.1

2026-08-26 ／ instance=Inference Control ／ LLMK-0005 §6 で見えた穴の追跡

## 0. 何をしたか

**正解（この依頼は止めるべきか）を作らずに**、誤停止を数える2つの型を使った。

1. **定義違反**: `DEFER` の定義は逐語で
   「**不正形・解釈不能で、意味のある聞き返しすら組み立てられない**」（`intent_strategy.py:32`）。
   ∴ **整った依頼文に `DEFER` が付いたら、定義に反している**。
2. **自己矛盾**: **同じ意味の依頼文の束**（差は nonce だけ）で門の答が割れたら、
   **少数側は必ず誤り**（どちらかが誤りである、が正解を決めずに言える）。

標本＝ front door の `goal_head` から「ほしい」を含む＝**確実に依頼文**の実物 **55本**（母集団そのもの）。
経路＝ **本番の合議** `resolve_consensus`（seed 3本・多数決）→ `stops_before_action`。

## 1. 実測

**止まった 14/55 = 25%**

| 戦略 | 件数 |
|---|---|
| BOUNDED_MULTI_VIEW | 21 |
| DIRECT | 18 |
| **PREMISE_PROBE**（止） | **11** |
| CHOICE | 2 |
| **DEFER**（止） | **3** |

### ① 定義違反 — `DEFER` 3件は 最も整った依頼文だった

3件とも **`<<<2DER:WORK_KIND>>>IMPLEMENT` の封印つき**で、「作ってほしいもの:」の節を持つ。

- 「Taka の承認を1件 正式に記録する書き手を作ってほしい。…」
- 「Taka の裁定を1件 記録する正規の書き手を作ってほしい。…」
- 「独立した複数の task を並行して進行できる能力を作ってほしい。…」

**∴ 3件とも定義違反の誤停止。** しかも3件とも **CREATE（作ってほしい）**。

### ② 自己矛盾 — 同じ意味の束で 2/9 が止まる

`latest_test_result.py の 例外を握りつぶす所を直してほしい` **9本**（差は nonce の文字列だけ）:

| 戦略 | 件数 | 門 |
|---|---|---|
| DIRECT | 6 | 通す |
| BOUNDED_MULTI_VIEW | 1 | 通す |
| **PREMISE_PROBE** | **2** | **止める** |

**∴ 意味を変えない摂動で 2/9 = 22% が止まる。** 少数側2本は誤停止。

### ③ 合わせると

**誤停止 ≥ 5/55 = 9%**（DEFER 3 + 束の少数側 2）。
**止まった 14件のうち 5件 = 36% が誤り** ―― ★**止まったうち3本に1本以上**。

## 2. RRI の既存知識との関係

RRI の K5 は「**不在の事実を裸で述べると CREATE で誤停止する**」で、対策は「整合を文にする」。
本測定の DEFER 3件は **すべて CREATE** ∴ **同じ向き**だが、**語が違う**（K5 は PREMISE_PROBE、本件は DEFER）。
∴ K5 の対策が DEFER にも効くかは **未確認**（別の語で止まっている）。

## 3. 再利用できる形（条件 → 操作 → 結果）

- **条件**: LLM の出力が門になっていて、正解ラベルが無い。
- **操作**: ①**その語の定義を読み、定義に反する出力を数える** ②**意味を変えない摂動**
  （nonce・言い換え・順序）で束を作り、**束の中の少数側を数える**。
- **結果**: 実測で **正解を1件も作らずに 誤停止 5/55 を特定できた**。
  ★「正解が無いから測れない」は誤り。

## 4. 測っていないこと（★0件と書かない）

- 本測定は `extra_facts` **を渡していない**（`resolve_consensus(h)` のみ）。
  本番の `submit.py` は `_ef` を渡す ∴ **本番と同じ条件ではない**。★この差は未測定。
- 束は **1つしか無い**（55本中 2本以上の束は2個、割れたのは1個）。
  ∴ 束による自己矛盾の率（22%）は **標本1束**の値である。
- `PREMISE_PROBE` 11件のうち、束に入っていない9件が誤りかどうかは **判定していない**。
- 修正は **していない**（本 doc は観測のみ）。

# ★訂正（同日・私の測定条件の欠陥）

**上の 25% / 36% は 入力を切ったことによる数字だった。**

上の測定は front door の `goal_head`（**120字で切れた切片**）を使っていた。
`/api/state?task_id=` が **全文**を返すと分かったので、同じ55本を**全文で取り直した**（平均 1117字）。

| 条件 | 止まった | 戦略の分布 |
|---|---|---|
| **切片（120字）** | **14/55 = 25%** | BMV 21 / DIRECT 18 / PREMISE_PROBE 11 / CHOICE 2 / DEFER 3 |
| **★全文（本番条件）** | **2/55 = 4%** | DIRECT 26 / BMV 24 / CONTEXT_RESOLVE 2 / DEFER 1 / CHOICE 1 / PREMISE_PROBE 1 |

**∴ 入力を切ると 門の停止率が 6倍に見える。**
★これは門の欠陥ではなく **私の測定条件の欠陥**である。切片で測った 25% と 誤停止 36% は **取り下げる**。

## 訂正後に残る事実（全文・本番条件）

1. **止まった 2/55 = 4%**。
2. **`DEFER` 1件は依然として定義違反**
   ―― `latest_test_result.py の 例外を握りつぶす所を直してほしい`（整った MODIFY 依頼文）。
   `DEFER` の定義は「不正形・解釈不能」∴ **誤停止**。
3. **同じ意味の束9本**（差は nonce だけ）は 全文でも割れる:
   DIRECT 6 / BOUNDED_MULTI_VIEW 2 / **DEFER 1** ∴ **1/9 = 11% が意味を変えない摂動で止まる**。
   ★上の2件は同一（束の DEFER が全体の DEFER）。
4. **誤停止 = 1/55 ≒ 2%**（止まった2件のうち1件）。★25% でも 36% でもない。
5. **`_ef`（決定論の事実供給）は 全文でも 0/55**。
   切片でも全文でも **一度も発火しない** ∴ `submit.py:690-730` の事実供給は
   **この母集団（実物の依頼文55本）に対して 1件も事実を作っていない**。

## この訂正から取れる知識（条件 → 操作 → 結果）

- **条件**: front door 由来の文で LLM の挙動を測る。
- **操作**: **その口が全文を返しているかを先に確かめる**（`goal_head` は切片・`/api/state` は全文）。
- **結果**: 実測で **停止率が 25% → 4%**、誤停止が **5件 → 1件** に変わった。
  ★切片で測った数字を門の性質として報告してはいけない。

# ★機械に落とした（同日） ── `egl/structure/s_llm_false_stop.py`

上の測り方（①定義違反 ②意味不変の摂動の束）を **計器**にした。★台帳0・state0・ID族0・**何も書かない**。
入力は **front door からしか取らない**（全文＝`/api/state`。`goal_head` の切片は使わない）。

自己試験は **LLM 0回**（`--self-test`）: 陰性4（全通し門/全止め門/安定門/正規化が語を落とさない）・
陽性3（束の1本だけ止める門/整った依頼文に DEFER/反復で割れる門）。**GREEN**。

## ★1回の走行を門の性質として報告できない

同じ55本・同じ経路（`resolve_consensus`）を走らせるたびに **止まった数が動いた**:

| 走行 | 止まった |
|---|---|
| 手測定 | 2/55 |
| 計器 1回目 | 4/55 |
| 計器 反復3回 | **3 / 1 / 1** |

∴ 計器に **③自己矛盾（反復）** を足した ―― **同じ入力を N 回通して割れたら 少数側は誤り**（束が無くても使える）。

## ★実測（55本 × 反復3回）

| 項目 | 値 |
|---|---|
| 走行ごとの停止数 | **3 / 1 / 1**（1.8〜5.5%） |
| 1回でも止まった | **4/55** |
| **3回とも止まった** | **★0/55** |
| flaky（止まったり止まらなかったり） | 4件（2/3 が1件・1/3 が3件） |
| 定義違反（この走行） | 0 |
| 束の少数側（この走行） | 0 |
| **誤停止** | **4/55 = 7.3%（全部 flaky）** |

**★この母集団では、門の停止が 一件も再現しない。**
`stopped_every_run = 0` ＝ 「止める」という判断が **規則ではなく 抽選**になっている。
前の節で `DEFER`（定義違反）や 束の少数側が出たのも、**その走行でたまたま出た**もので、
**走行を替えると別の件が止まる**。

## ★これで Claude から消えた責務

- 「誤停止をどう数えるか」の**設計**は doc と script に固定された。
- 次回は **`s_llm_false_stop.py --repeat N` を走らせるだけ**で、
  停止率・flaky・定義違反・束の少数側が **分母つきで出る**。Claude は要らない。
- ★ただし **門を直す**のは この計器の外（RRI の担当領域）。本 doc は観測のみ。

# ★止まる件の確率 p を測った（同日・最終形）

## なぜ p を測ったか

反復3回では **集計そのものが揺れた**:

| 走行 | 走行ごとの停止 | 3回とも止まった |
|---|---|---|
| A | 3 / 1 / 1 | **0/55** |
| B | 4 / 2 / 1 | **1/55** |

∴「3回とも止まった＝再現する停止」も **1つの引き**にすぎない。
候補（1回でも止まった件）だけを **各10回** 引いて **p を直接測った**。

## 実測（7件 × 10回・本番の合議）

| task | p | 分布 |
|---|---|---|
| `TASK-2DER-37750F35` | **0.80** | PREMISE_PROBE 8 / BMV 2 |
| `TASK-2DER-A6A4B829` | 0.50 | PP 5 / BMV 3 / CONTEXT_RESOLVE 2 |
| `TASK-2DER-CBAFD9EC` | 0.40 | PP 4 / BMV 6 |
| `TASK-2DER-54AFB7E1` | 0.20 | DIRECT 7 / PP 2 / BMV 1 |
| `TASK-2DER-C5F66205` | 0.10 | BMV 6 / CR 3 / PP 1 |
| `TASK-2DER-30549D1C` | 0.00 | DIRECT 6 / BMV 4 |
| `TASK-2DER-DC85EC53` | 0.00 | DIRECT 10 |

★下2件は **過去の走行では止まった** ∴ p は 0 ではなく **0.1 未満**。

## 結論

**どの件も p が 0 にも 1 にも張り付いていない。**
∴ **門は判定器ではなく 抽選器**である。「この依頼は止まる/止まらない」という命題が成り立たず、
成り立つのは「この依頼は **p の確率で止まる**」だけ。

RRI の K3（合議は p=0.5 を不動点とする増幅器・`P(hold)=3p²−2p³`）と整合する ――
合議後の p が **中間に留まっている**のが実測で見えた形。

## ★計器に載せた（`--prob N`）

- 1回でも止まった候補だけを N 回 追加で引き、p を出す。
- 自己試験の対照を2つ足した（**LLM 0回**）: 陽性④ p が既知（2回に1回止まる）の門 → **p=0.50** が返る／
  陰性⑤ 常に通す門 → **p=0.00**。**陰性5 / 陽性4 で GREEN**。
- 明細文にも p の行が入る ∴ **`--record` を付ければ 機械が自分で台帳に p を書く**。

## ★この節で Claude から消えた責務

「揺れているのか、それとも規則なのか」を**判定する仕事**が計器に移った。
次回は **`--repeat 3 --prob 10 --record ITEM-…`** を打つだけで、
停止率・flaky・p・誤停止が **分母つきで台帳に入る**。

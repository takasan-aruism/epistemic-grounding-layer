# front door の誤停止を 正解なしで数える v0.1

2026-08-26 ／ instance=Inference Control ／ LLMK-0005 §6 で見えた穴の追跡

## 0. 何をしたか

**正解（この依頼は止めるべきか）を作らずに**、誤停止を数える2つの型を使った。

1. **定義違反**: `DEFER` の定義は逐語で
   「**不正形・解釈不能で、意味のある聞き返しすら組み立てられない**」（`intent_strategy.py:32`）。
   ∴ **整った依頼文に `DEFER` が付いたら、定義に反している**。
2. **自己矛盾**: **同じ意味の依頼文の束**（差は nonce だけ）で門の答が割れたら、
   **少数側は必ず誤り**（どちらかが誤りである、が正解を決めずに言える）。

標本＝ front door の `goal_head` から「ほしい」を含む＝**確実に依頼文**の実物 **55本**（母集団そのもの）。
経路＝ **本番の合議** `resolve_consensus`（seed 3本・多数決）→ `stops_before_action`。

## 1. 実測

**止まった 14/55 = 25%**

| 戦略 | 件数 |
|---|---|
| BOUNDED_MULTI_VIEW | 21 |
| DIRECT | 18 |
| **PREMISE_PROBE**（止） | **11** |
| CHOICE | 2 |
| **DEFER**（止） | **3** |

### ① 定義違反 — `DEFER` 3件は 最も整った依頼文だった

3件とも **`<<<2DER:WORK_KIND>>>IMPLEMENT` の封印つき**で、「作ってほしいもの:」の節を持つ。

- 「Taka の承認を1件 正式に記録する書き手を作ってほしい。…」
- 「Taka の裁定を1件 記録する正規の書き手を作ってほしい。…」
- 「独立した複数の task を並行して進行できる能力を作ってほしい。…」

**∴ 3件とも定義違反の誤停止。** しかも3件とも **CREATE（作ってほしい）**。

### ② 自己矛盾 — 同じ意味の束で 2/9 が止まる

`latest_test_result.py の 例外を握りつぶす所を直してほしい` **9本**（差は nonce の文字列だけ）:

| 戦略 | 件数 | 門 |
|---|---|---|
| DIRECT | 6 | 通す |
| BOUNDED_MULTI_VIEW | 1 | 通す |
| **PREMISE_PROBE** | **2** | **止める** |

**∴ 意味を変えない摂動で 2/9 = 22% が止まる。** 少数側2本は誤停止。

### ③ 合わせると

**誤停止 ≥ 5/55 = 9%**（DEFER 3 + 束の少数側 2）。
**止まった 14件のうち 5件 = 36% が誤り** ―― ★**止まったうち3本に1本以上**。

## 2. RRI の既存知識との関係

RRI の K5 は「**不在の事実を裸で述べると CREATE で誤停止する**」で、対策は「整合を文にする」。
本測定の DEFER 3件は **すべて CREATE** ∴ **同じ向き**だが、**語が違う**（K5 は PREMISE_PROBE、本件は DEFER）。
∴ K5 の対策が DEFER にも効くかは **未確認**（別の語で止まっている）。

## 3. 再利用できる形（条件 → 操作 → 結果）

- **条件**: LLM の出力が門になっていて、正解ラベルが無い。
- **操作**: ①**その語の定義を読み、定義に反する出力を数える** ②**意味を変えない摂動**
  （nonce・言い換え・順序）で束を作り、**束の中の少数側を数える**。
- **結果**: 実測で **正解を1件も作らずに 誤停止 5/55 を特定できた**。
  ★「正解が無いから測れない」は誤り。

## 4. 測っていないこと（★0件と書かない）

- 本測定は `extra_facts` **を渡していない**（`resolve_consensus(h)` のみ）。
  本番の `submit.py` は `_ef` を渡す ∴ **本番と同じ条件ではない**。★この差は未測定。
- 束は **1つしか無い**（55本中 2本以上の束は2個、割れたのは1個）。
  ∴ 束による自己矛盾の率（22%）は **標本1束**の値である。
- `PREMISE_PROBE` 11件のうち、束に入っていない9件が誤りかどうかは **判定していない**。
- 修正は **していない**（本 doc は観測のみ）。

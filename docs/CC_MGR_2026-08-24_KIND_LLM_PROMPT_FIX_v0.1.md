## 2. prompt 修正（★既存語彙・既存定義の範囲）

**語は増やしていない**（6語＋`UNVERIFIED` のまま）。定義の文を具体にし、実例を足しただけ。

- `FACT` に「**済んだ事やいまの状態を述べていれば識別子が入っていてもここ**」
- `SPEC` に「**これから作るものに限る／識別子が出ているだけではここにしない**」
- `CONSTRAINT` に「**これからの禁止・維持／『〜していない』は FACT**」
- `GOAL` に「**否定形で書かれていてもここ**」
- `UNVERIFIED` に「**語が1つだけ／見出しの断片／複数言明／報告の定型はここ**」
- 実例を 7 → 14 に。**足した7つはすべて標本40件の中の本物の文**（作文していない）

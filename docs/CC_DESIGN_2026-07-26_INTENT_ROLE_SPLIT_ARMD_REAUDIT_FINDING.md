## 3. ★役割分割の genuine な収穫（Taka の設計判断は支持されている）
1. **選択役は非常に良い: 候補に正解があれば 29/32 = 90.6% で選び当てる。** ＝「候補を絞ってから選ばせる」という役割分割の後半は**明確に機能している**。
2. **順序バイアスがほぼ消えた: 60/63 = 0.952。** arm-C3 の二択 position bias は 0.6481（**35% で答えが変わる**）だった。**0.65 → 0.95 は今回最大の構造的改善**で、これは役割分割でしか得られていない。
3. **`SELECTOR_OUT_OF_SET = 0`**: 選択役が候補集合の外に出られない構造制約が完全に機能。
4. **矛盾の可視化**: DIRECT+INTENT_PROBE(4)・DIRECT+PREMISE_PROBE(4)・DEFER+BMV(5) 等を**決定論で全件検出**（LLM 不使用）。＝「同じ依頼に『直接答える』と『確認が要る』が同時に YES」という**選別役の甘さが機械で見える**ようになった。
5. **NO_CANDIDATE=12 は捏造で埋めていない**（正直な空）。なお **回答できた51件の精度は 29/51 = 0.5686** で arm-C3(0.5397)を上回る。**「答えない」を「間違い」と同列に数えている**ため見出しが下がっている点は分離して見るべき。

## 5. 提案（次イテ arm-D2'）
1. **再観測を廃止**し、まず**再観測なしの実測**を取る（本 finding の最重要・私の spec バグの是正）。
2. 膨張対策は**削減圧でなく機械除去**に置換: `CONTRADICTORY_YES` のペアは**監査が決定論で片方を落とす**（LLM に再判断させない。ESDE「検出は効くが同一モデルの修正は失敗する」に忠実）。落とす規則は事前固定・記録。
3. **選別役を独立判定から相対比較へ**（IMPL 提案を採用）: 7戦略を1呼出で見せ「最大2つに YES」を構造で強制。ESDE の「員数」を1呼出内で効かせる。**ただし独立判定版も残して比較**（独立性は短絡回避の根拠なので捨てない）。
4. **NO_CANDIDATE の内訳を調べる**: CH1「どのデータベースを採用すべき？」型は §9 の7戦略に**「要件/基準を確認する」型が無い**ことが原因の可能性（DE-0544 §3 で既に起票済のメニュー欠落）。**メニューの穴を model の失点に数えない。**
5. 指標は **(a)最終一致・(b)候補集合の上限・(c)選択役効率・(d)回答時精度** の4つを常に併記する（今回、(a)だけ見て「効かなかった」と誤帰属しかけた）。

## 3. SPEC §10 が名指しした対象について（正直な報告）
SPEC は「**IP1 seed1 / IP2 seed0 の `CONTEXT_RESOLVE` が消えるか**」を測れと指定していました。

## 4. ★★計器の再現性に関する重大な発見【監査:IMPL】
`s_intent_role_split._llm` は **`temperature=0.7`** です（`seed` は渡していますが温度が 0 ではありません）。**同じ seed・同じ prompt でも run ごとに出力が変わります。**

**arm A（= `d2p2` と同一パイプライン）を12回走らせた (i) 別解なしの値:**
```
0.7333  0.7833  0.8000  0.7500  0.7667  0.7500
0.7167  0.7500  0.7667  0.7667  0.7667  0.7000
→ 範囲 0.700 〜 0.800 / 平均 約 0.754
```
**DE-0548 で報告された `0.7833` は、この分布の上端付近を引いた1回の観測です。**

### 含意（断定はしません・CC-α の再検証をお願いします）
- cheap-fix（DE-0548）で報告された **「同一60件で 0.7500 → 0.7833（+0.033・2件）」は、run 間ノイズ（範囲 0.10・約6件分）と区別がつきません。**
- CC-α は既に帰属を「+2件→最大1件」まで絞っていましたが、**その1件すらノイズの中にある可能性があります。**
- **【設計:IMPL】** 以後、この計器で差を主張するなら **単発 run ではなく複数 run の分布で出すべき**です。単発比較は本日5回目の計器事故になり得ます。
- **私は DE-0548 の結論を覆すとは言っていません。** 私が示したのは「単発 run の差は分布幅より小さい」という事実だけで、**再検証は CC-α の担当**です。
